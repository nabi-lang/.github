# Getting help

- **Questions, ideas, show and tell**:
  [GitHub Discussions](https://github.com/nabi-lang/nabi/discussions). This
  is Nabi's only community channel. Search it first; your question may
  already have an answer.
- **Documentation**: the guide, the standard library API and the spec at
  [docs.nabi-lang.org](https://docs.nabi-lang.org). Each error code has a
  page there (`nabic --explain <code>` prints it).
- **Try something quickly**: the
  [playground](https://playground.nabi-lang.org).
- **A bug**: open an issue in the repository it concerns, with the version
  (`nabi version -v`), the OS and architecture, and a minimal example.
  Not sure which repository? Use
  [nabi-lang/nabi](https://github.com/nabi-lang/nabi/issues).
- **A security issue**: never in public. See [SECURITY.md](SECURITY.md).
- **A Code of Conduct concern**: conduct@nabi-lang.org. See
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Nabi is maintained by volunteers. There is no paid support and no
guaranteed response time outside the security policy.
